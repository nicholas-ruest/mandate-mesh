# Specification

## Problem and users
Agent-platform operators can discover many agents but lack a trustworthy way to form a team for a multi-step objective. Static roles ignore context-dependent capability; unconstrained delegation can violate separation of duty, residency, budget or least authority; ordinary logs cannot prove which scoped mandate existed after restart.

Mandate Mesh serves platform operators and agent-team leads. It accepts a deterministic synthetic incident-response objective, forms a four-role team, executes real policy/intelligence/persistence boundaries and returns a durable delegation contract.

## Capability
Given an objective, task DAG and candidate agents, issue a least-authority contract only when every role has a calibrated lower bound, the team satisfies policy and budgets, and analogue evidence improves but never overrides feasibility.

## Acceptance
1. Browser issues and renders a four-step contract through real Rust behavior.
2. Restricted external-only candidates are denied with no append; adding an internal specialist recovers.
3. Refresh and restart return the same contract receipt.
4. Combined evaluation exceeds ingredient-removal modes.
5. Exact-SHA quality, browser, container and semantic evidence pass.
