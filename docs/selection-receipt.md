# SELECTION_RECEIPT  2026-10-25  Mandate Mesh

## Capability
Mandate Mesh forms a policy-safe team of specialized agents for a multi-step objective, issues least-authority task mandates, monitors completion/refusal, and durably replays the delegation contract and audit after restart.

## Distinctness
This is not provenance containment, failover, context transfer, prospective action authorization, canary rollout, causal incident reconstruction, SLO exception control, purpose governance, or single-provider inference routing. Route Foundry selects one model provider for one inference; Mandate Mesh composes several agents into a dependency-aware task graph with separation-of-duty, scoped contracts, refusal/reassignment, and team-level calibrated assurance.

## Users and workload
Platform operators and agent-team leads submit a synthetic incident-response objective. The system decomposes it into plan, investigate, remediate, and verify mandates; selects a feasible multi-agent team; enforces role separation and data-boundary policy; persists the signed contract; exposes progress and audit in a React product; and restores the same contract after service restart.

## Composition
- RuVector Core 2.4.0, repository c44d7337c0c5ad2ecd2294178475387facb96516: insert/search analogous successful team compositions.
- RVF Runtime 0.3.2, same RuVector source family: append/reopen/read durable mandates and audit.
- Microsoft Regorus 0.13.0, repository 99f794a43c3815563597aa076e4b2e3c3bbaf942: execute Rego separation-of-duty and restricted-data rules.
- Frontier mechanism: contextual capability calibration for multi-agent delegation, strengthened by selective conformal risk control so uncertain role assignments abstain rather than silently allocate.

## Success criteria and ablations
- Browser journey creates a four-step contract through real API, Regorus, RuVector and RVF boundaries.
- Restricted external-only team is denied with no durable contract, then recovers with an internal specialist.
- Saved contract is byte-equivalent after refresh and backend restart.
- Structural floor: >=20 meaningful linked Rust crates, 25 ADRs, 12 DDD docs.
- Combined utility must exceed Ruvnet-only, enterprise-only, no-calibration, and no-recall modes.
- Removing Regorus admits a forbidden assignment; removing RuVector loses analogue gain; removing RVF loses restart recovery; removing calibration reduces safe coverage.
